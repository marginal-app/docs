## 로컬 우선

밑줄과 코멘트는 확장의 IndexedDB에 먼저 저장됩니다. 서버가 없거나 오프라인이어도 긋고, 읽고, 고칠 수 있습니다.

## 동기화

서버와 토큰이 설정되어 있으면 백그라운드가 주기적으로 **pull**과 **push**를 합니다. 사이드패널은 이것을 밑줄 단위로 보여줍니다.

| 상황 | 동기화 줄 | 밑줄별 표시 |
| --- | --- | --- |
| 토큰 없음(로컬 전용) | 없음 | 없음 |
| 토큰 있음, 오프라인 | 없음 | 없음 |
| 온라인, 밀어내는 중 | 동기화 중 · 대기 n | 저장 중… |
| 온라인, 완료 | 동기화됨 · 시각 | 동기화됨 · 방금 |
| 서버 오류 | 서버 오류 · 대기 n · 재시도 | 저장 실패 · 재시도 |

오프라인은 실패가 아닙니다. 표시가 사라질 뿐이고, 연결되면 밀린 것을 보냅니다.

## 충돌

같은 밑줄을 두 기기에서 고쳤다면 서버는 나중 것을 거부하고, 확장이 서버 버전 위에 다시 얹습니다.
