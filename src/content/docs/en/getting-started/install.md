---
title: Install the extension
description: Install the Marginal extension for Chrome or Firefox.
---

Marginal consists of a browser extension and an optional self-hosted server. You can get started with the extension alone.

## Chrome

1. Download and extract the latest `chrome-mv3` zip from [GitHub Releases](https://github.com/marginal-app/marginal-app/releases).
2. Open `chrome://extensions` and turn on **Developer mode** in the top-right corner.
3. Select **Load unpacked** and choose the extracted directory.

## Firefox

1. Download the `firefox` zip from the same release.
2. Open `about:debugging#/runtime/this-firefox`, select **Load Temporary Add-on**, and choose the zip.

Immediately after installation, Marginal works in **local-only** mode. Your highlights remain in this browser. To connect a server, see [Run the server](/en/self-host/server/).
