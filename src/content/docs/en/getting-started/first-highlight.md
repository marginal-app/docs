## Create a highlight

Select text on any page to open the **color toolbar**. Choose one of the five colors to create a highlight. The colors have no predefined meaning, so you can use whatever system works for you.

## Add a comment

Select a highlight to open the **comment popover**. Write a note and select **Save**. Select **View in context** to scroll back to the highlight.

## Use the side panel

Select the extension icon to open the side panel, which collects the highlights from the page you are viewing.

- The **document card** at the top includes the page title, host, highlight count, and buttons for **Bookmark** and **Open on web**.
- A new highlight appears at the top immediately. If a server is connected, its state changes from **Saving → Synced**.
- Without a server, sync indicators are hidden entirely rather than appearing as failures.
