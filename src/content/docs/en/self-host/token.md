---
title: Create an API token
description: Create the token that the extension uses to communicate with your server.
---

1. Sign in to the server and open **Settings** (`/identity/settings/`).
2. In the **API token** section, select **Create token**.
3. The plain-text token appears **only once, immediately after creation**. Copy it before leaving the page; afterward, only its final characters remain visible.

If you lose the token or suspect that it has been exposed, select **Regenerate**. The previous token becomes invalid immediately.
