---
title: Connect the extension
description: Add your server URL and token to the extension settings and verify the connection.
---

1. Select the **Settings** icon in the top-right corner of the side panel.
2. Enter your server address (for example, `http://127.0.0.1:8000`) under **SERVER URL** and your [API token](/en/self-host/token/) under **API TOKEN**.
3. Select **Save and test connection**. A `CONNECTED` badge appears when the connection succeeds.

Once connected, the extension uploads existing highlights from this browser and downloads highlights from the server. Use **Open on web** on a document card to view that page's highlights in the web library.
