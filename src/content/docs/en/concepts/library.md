---
title: Contents, highlights, bookmarks, and comments
description: The four views and detail tray in the web library.
---

The web library (`/library/`) presents the same data in four tabs:

- **Contents** — A numbered list of pages you marked, including title, host, and highlight count.
- **Highlights** — Highlights from every page in chronological order.
- **Bookmarks** — Pages you saved without adding a highlight.
- **Comments** — Only highlights that have comments.

Select an item in any tab to open the **tray** on the right. The tray shows the page's document card and highlights. If you selected an item in the Highlights or Comments tab, its comment editor opens with that highlight selected. The list remains visible.

The home page (`/`) presents this week's summary, recent highlights, frequently revisited pages, and bookmarks as widgets.
