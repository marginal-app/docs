title: 첫 밑줄
description: 문장을 드래그해서 밑줄을 긋고, 코멘트를 남기고, 사이드패널에서 다시 봅니다.
---

## 밑줄 긋기

아무 페이지에서 문장을 드래그하면 **색 툴바**가 뜹니다. 다섯 색 중 하나를 누르면 밑줄이 됩니다. 색의 뜻은 정해져 있지 않습니다. 각자 편한 규칙을 쓰면 됩니다.

## 코멘트

밑줄을 누르면 **코멘트 팝오버**가 열립니다. 메모를 적고 **저장**을 누릅니다. **원문으로**를 누르면 밑줄 자리로 스크롤합니다.

## 사이드패널

확장 아이콘을 누르면 사이드패널이 열리고, 지금 보고 있는 페이지의 밑줄이 모입니다.

- 위쪽 **문서 카드**에는 페이지 제목과 호스트, 밑줄 수가 있고 **북마크**와 **웹에서 열기** 버튼이 있습니다.
- 밑줄을 그은 직후에는 목록 맨 위에 바로 나타나고, 서버가 연결되어 있으면 **저장 중 → 동기화됨**으로 바뀝니다.
- 서버가 없으면 동기화 표시 자체가 없습니다. 실패로 보이지 않습니다.
